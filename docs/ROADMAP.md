# BioMEMS Design-to-Fab Hub Roadmap

Every release delivers one primary capability and a working GUI milestone.

| Version | Single capability | GUI milestone |
| --- | --- | --- |
| V0.0.1 | Pin and verify the third-party baseline | KLayout upstream PCell smoke test |
| V0.1.0 | Remove legacy user-facing identity | Hub name and modern application identity |
| V0.2.0 | Create or open a Hub project | Modern desktop project-home window |
| V0.3.0 | Edit and validate a device manifest | Device Manifest form with inline validation |
| V0.4.0 | Configure one trapping-array design | Parametric Design workspace and geometry summary |
| V0.5.0 | Export one immutable design package | Export panel for GDS, SVG, manifest and hashes |
| V0.6.0 | Run advisory geometry checks | Check Design view with PASSED, FAILED or INCOMPLETE state |
| V0.7.0 | Create one process traveler | Traveler form with immutable run UUID |
| V0.8.0 | Attach one QC evidence record | QC record form with source-file hash and review status |
| V1.0.0 | Reproduce one synthetic reference workflow end to end | Integrated modern Hub GUI |

The first scientific demonstration uses synthetic data and is labelled as a
microfluidic trapping-array research example. It must not claim cell-capture,
diagnostic, fabrication-yield or medical-device performance.
